# 工作流名称

## 适用场景

当用户询问……时使用此工作流。

## 所需的 LLMQuant Data

必需：
- 用自然语言描述所需的数据能力，并说明原因。

可选或未来：
- 描述可选或未来的数据能力，并说明其用途。

时效性：
- 注明观察日期、报告期间、数据截止日期及过期数据提示。

回退规则：
- 若某项必需输入不可用，指明缺失的 LLMQuant Data 输入，并仅使用已获取的证据继续。

## 工作流

1. 确认标识、时间范围及输出目标。
2. 拉取所需的 LLMQuant Data。
3. 检查覆盖范围、日期及缺失字段。
4. 将证据与解读分开。
5. 按下方格式生成输出。

## 输出格式

1. **结论**
2. **证据**
3. **情景 / 敏感性分析**
4. **风险 / 注意事项**
5. **所用数据**

## 防护栏

- 不得编造缺失值。
- 不得将模型输出呈现为数据。
- 不得做出个性化投资建议的声明。
